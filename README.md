# Las crónicas de Carlos Mendoza

Historia de fan, sin fines de lucro: un técnico en logística vive cuatro aventuras con C-3PO y R2-D2 en momentos de la trilogía original de Star Wars que las películas no muestran.

**Ver el sitio:** https://thelexmendoza.github.io/cronicas-carlos-mendoza/

- Se recorre con scroll o con las flechas del teclado. El índice lateral (scrollspy) marca la sección actual.
- Haz clic en los pitidos de R2 para traducirlos y en las citas de 3PO para escucharlas.
- Botón de música abajo a la izquierda (o tecla M): banda sonora de John Williams desde YouTube, con una pista distinta por sección.
- Para imprimir o exportar a PDF (16:9), usa Imprimir → Guardar como PDF en Chrome o Edge.

Fondos: fotografías de [Unsplash](https://unsplash.com). Star Wars, C-3PO y R2-D2 son propiedad de Lucasfilm Ltd.
